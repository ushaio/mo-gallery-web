# Desktop Agent 扩展能力 — 首期规格

## 1. 设置入口

系统设置新增“Agent 扩展”一级标签，采用 Desktop 现有 master-detail 语言：左侧为 Skills/MCP/权限与审计三个分区，右侧展示选中项详情；选中项、折叠状态和启用状态持久化。

### Skills 分区

- 导入本地目录或 `.skill`/`.zip`。
- 解包前阻止路径穿越、绝对路径、符号链接逃逸和重复文件覆盖。
- 读取并校验 `SKILL.md` frontmatter；展示名称、描述、版本、来源、校验状态和内容指纹。当前版本对缺失/非法文件直接拒绝导入，不持久化 invalid catalog 项；已安装快照后续校验失败时仍可使用 `validationStatus=invalid` 表示不可用状态。
- 默认启用 Skill，但 `scripts/` 执行权限默认关闭。
- 支持启用/禁用、移除、重新导入新版本；保留当前快照直到新版本校验通过。

### MCP 分区

- 支持导入/粘贴通用 `mcpServers` JSON，并提供表单编辑 command、args、env 引用和权限。
- 首期只允许 stdio；HTTP/SSE 配置应被明确标记为不支持而非静默忽略。
- 提供“测试连接”：按需启动、初始化、列出工具、关闭进程；测试不得自动授予 Agent 调用权。
- 展示 stopped/starting/ready/degraded/crashed、最近错误、最近使用和能力指纹。
- 可设置启用状态、超时和空闲关闭策略（默认值由实现阶段确定）。

### 权限与审计分区

- 按扩展、工具、风险等级和参数范围查看/撤销授权。
- 支持清除单项授权、清除某扩展全部授权。
- 展示调用元数据、脱敏参数摘要、状态和耗时；禁止查看密钥明文。

## 2. Agent 助手页集成

1. Agent 首先读取启用扩展的元数据，基于任务语义自动匹配 Skill。
2. 用户可在会话级扩展面板中查看、关闭或显式启用候选 Skill/MCP；当前版本已提供轻量面板，状态仅保存在前端会话内，不写入全局配置。
3. 仅把已启用、校验通过且当前授权允许的 MCP 工具暴露给 `packages/ai-agent` 工具循环；MCP 工具发现当前使用 Server 快照中已缓存的 tools，首次使用前仍需在设置页测试连接。
4. Skill 完整指令和引用资料按匹配结果按需加载，不把全部扩展内容常驻上下文。
5. 工具调用通过 Wails bridge 进入 Go supervisor；前端/模型不能直接创建进程。
6. 低风险读取若有匹配的 remembered grant 可直接执行；高风险能力每次调用前确认。remembered grant 必须检查指纹和 `ExpiresAt`，过期授权不可放行。
7. MCP 首次调用按需启动；空闲超时关闭。崩溃/无响应自动重启一次，仍失败则当前任务降级。模型停止时会向工具执行边界传递 AbortSignal；当前 Wails 单次调用仍缺少 Go 侧可取消 invocation ID，因此外部 MCP 请求最多运行到自身超时。
8. 工具结果回传给 Agent；审计写入元数据和脱敏摘要；权限等待路径也安排 runtime idle 回收。

## 3. 安全与数据

- Secret 环境变量只保存到系统凭据库，配置文件保存 credential reference。
- 删除、执行、写入和网络外发须使用显式授权；高风险调用不能继承“扩展已启用”。
- 任何内容或配置变更都会重新计算能力指纹，并使旧长期授权失效。
- 不持久化完整 MCP 原始输出、文件内容、API Key 或原始模型工具上下文。
- Windows 为完整验收平台；macOS/Linux 需保持可编译并通过抽象接口测试。

## 4. 明确不在首期

- HTTP/SSE MCP。
- Skill 脚本默认执行。
- Web 或 Mobile 接入。
- 故事/博客编辑器和 Zine 接入。
- 后台持续运行全部 MCP Server。
- 自动导入远程 Git Skill。
