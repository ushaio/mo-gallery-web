# ADR-0002：采用分层命令入口与次级视觉格式

- 状态：已接受
- 日期：2026-08-04

## 背景

当前编辑器将标题、字体、字号、粗体、颜色、高亮、列表、引用、首字下沉、对齐、链接、图片、媒体、表格、清除格式和撤销重做平铺在固定工具栏中；同时 Bubble Menu 与 Floating Menu 又暴露部分重复命令。工具栏在窄宽度下只能横向滚动，用户难以理解不同入口的职责。

## 决策

1. 固定主工具栏采用“精简主栏 + 更多菜单”。主栏只承担跨上下文、高频且需要稳定位置的命令。
2. 视觉排版能力全部保留，但字体、字号、文字颜色、高亮、对齐和首字下沉进入次级“格式/更多”菜单。
3. Bubble Menu 只处理当前文本选区的高频行内格式、链接和选区相关动作，不复制完整主工具栏。
4. `/` 菜单负责在当前插入点创建结构块与内容节点，包括标题、列表、引用、代码、分隔线、图片、媒体、表格和故事卡片。
5. 块拖拽手柄点击后打开块菜单，提供块类型转换、复制、删除、前插入和后插入；拖拽仍用于移动块。
6. 所有入口复用同一命令注册表，包含命令 ID、分类、标签、关键词、图标、快捷键提示、可见条件、可执行条件和执行函数。
7. 菜单打开、关闭、焦点恢复和 `Esc` 行为由统一浮层协调层管理，避免当前多个局部布尔状态互相冲突。

## 候选主工具栏

- 块类型/段落样式。
- 粗体、斜体等最常用行内格式，最终数量由可用宽度与 Bubble Menu 分工验证决定。
- 插入入口，打开与 `/` 菜单同源的命令面板。
- “格式/更多”入口。
- 撤销、重做。
- AI 侧栏开关在宿主启用时保持稳定位置。

## 未采用的方案

### A. 保持全部命令常驻

放弃原因：延续横向溢出与命令密度问题，无法建立清晰层级。

### B. 默认隐藏整个主工具栏

放弃原因：第一阶段目标包含功能发现效率，完全依赖上下文菜单会让新用户难以建立能力地图。

### C. `/` 菜单包含所有行内格式和历史命令

放弃原因：Slash Menu 的核心是插入和块转换；纳入所有格式会造成搜索结果噪音，并与选区菜单职责冲突。

### D. 手柄仅用于拖拽

放弃原因：用户仍缺少稳定、可发现的块级复制、删除、插入和转换入口。

## 后果

- 需要将当前 `toggle*`、`set*` 与插入函数迁移为共享命令描述。
- 需要实现免费自有 Slash Menu 与 Block Menu，并复用官方 Suggestion、Popover/Menu、Drag Handle 等模式。
- 需要定义响应式溢出策略和菜单优先级。
- 需要针对键盘导航、选区保持、焦点恢复与单次撤销补充测试。
