# Tiptap 编辑器体验优化规格

- 状态：已完成访谈，阶段 1-2 部分实施并完成静态回归；阶段 3-6 待实施
- 日期：2026-08-04
- 适用范围：`packages/tiptap-editor`、Web/Desktop Story、Web/Desktop Blog

> 交付边界（2026-08-04）：本轮已完成统一命令注册表、精简主工具栏、插入/格式菜单、官方 Bubble/Floating Menu 与 Drag Handle 接入、基础键盘和窄屏处理。Slash Menu、块菜单、统一上传状态机、链接/表格增强、保存状态、schema version 与历史 fixture 仍属于后续阶段，不计入本轮已验收范围。
>
> 后续更新（2026-08-05）：主工具栏命令条改为横向滚动，按钮命令取消断点隐藏并常驻；插入/格式/撤销重做固定常驻不裁切；字体/字号与重做常驻工具栏，格式菜单仅保留工具栏没有的命令（首字下沉、文字颜色、背景颜色），消除重复入口。见 ADR-0005。

## 1. 产品目标

把现有传统富文本编辑器升级为渐进式块编辑体验：普通写作保持直接、连续；结构插入、块操作和节点编辑在需要时出现。功能应优先建立在 Tiptap 免费官方模板、开源扩展和公开模式上，并通过共享包保证全端一致。

## 2. 成功标准

1. 核心写作、插入和块操作在主工具栏常驻可达；空间不足时命令条横向滚动，插入/格式/撤销重做固定不裁切。
2. 高频文本格式最多一次点击可达；低频视觉格式最多两次点击可达。
3. `/` 菜单可完全用键盘检索、执行和退出。
4. 块复制、删除、转换、前后插入和拖拽都有稳定入口，并保持单次撤销语义。
5. 图片粘贴、拖放和选择文件进入统一上传流程，失败可恢复。
6. Story/Blog、Web/Desktop 对同一命令具有一致标签、图标、快捷键、结果与存储结构。
7. 历史 HTML/JSON 与自定义节点可以继续读取和编辑，不发生静默内容丢失。

## 3. 信息架构

### 3.1 固定主工具栏

常驻：

- 当前块类型。
- 粗体、斜体等经验证的最高频行内格式。
- 插入菜单入口，与 Slash Menu 共用命令源。
- 格式/更多菜单入口。
- 撤销、重做。
- AI 侧栏开关（启用时）。
- 保存状态指示。

不常驻：颜色、高亮、首字下沉、表格细项、图片 URL 输入。字体、字号、对齐随命令条常驻。

空间不足时，命令条（块类型、字体/字号、基础格式、列表、引用、对齐等）横向滚动；插入、格式、撤销、重做固定在右侧，不随命令条滚动，菜单浮层不被裁切（ADR-0005）。

格式/更多菜单只保留工具栏没有的命令：首字下沉、文字颜色、背景颜色（2026-08-05 去重：斜体、下划线、删除线、行内代码、列表、引用、对齐、清除格式、重做、字体/字号均以工具栏为唯一入口）。

### 3.2 Bubble Menu

- 仅在非空文本选区出现。
- 提供粗体、斜体、下划线、删除线、链接、清除格式和“使用 AI”。
- 节点选择、代码块、AI 锁定时不显示文本菜单。
- Esc 关闭并恢复编辑区焦点；菜单内支持方向键导航。

### 3.3 Slash Menu

分类：

- 基础：段落、H1-H6。
- 列表：无序、有序，未来可追加任务列表。
- 结构：引用、代码块、分隔线。
- 媒体：图片上传、图片 URL、媒体嵌入。
- 内容：故事卡片。
- 表格：选择行列后插入。

规则：

- 仅在文本块中满足触发规则时打开。
- 支持中文标签、英文别名、拼音/关键词扩展。
- 支持搜索、分组、空结果、方向键、Enter、Esc。
- 执行后删除触发文本，并把光标放到可继续编辑的位置。

### 3.4 块手柄与块菜单

- Hover/当前块显示拖拽手柄；触控使用选中后的显式入口。
- 拖拽移动块；点击打开块菜单。
- 菜单提供转换、复制、删除、前插入、后插入。
- 删除最后一个块后保留可输入段落。
- 每个动作产生一个历史边界，无变化不入历史。

### 3.5 节点上下文工具

- 图片：替换、上传状态、替代文本、对齐/宽度、链接、删除。
- 表格：增删行列、表头、合并、拆分、删除。
- 媒体：编辑来源、打开来源、删除、错误恢复。
- 故事卡片：刷新、打开、转普通链接、删除。

## 4. 命令模型

建立共享 `EditorCommandDescriptor`：

- `id`：稳定命令 ID。
- `group`：block、inline、insert、format、table、media、ai、history。
- `labelKey`、`keywords`、`icon`、`shortcut`。
- `isVisible(context)`。
- `canExecute(context)`，内部结合 schema、selection、`editor.can()` 和任务锁。
- `execute(context)`，统一处理 chain、focus、selection 恢复和 transaction。
- `surfaces`：main、bubble、slash、block、node、overflow。

菜单只消费命令描述，不各自复制执行逻辑。

## 5. 浮层与焦点模型

1. 同一时刻只有一个主菜单处于打开状态。
2. 打开新菜单自动关闭同层级旧菜单。
3. Esc 先关闭最内层 Popover/Menu，再退出节点编辑态，最后把焦点交还编辑区。
4. 点击外部按当前交互类型提交或关闭；图片上传等异步状态不因菜单关闭而取消。
5. 桌面工具栏支持 Alt+F10 聚焦，方向键在同组控件间移动。
6. 所有 icon button 有可访问名称、Tooltip、disabled 原因和可见焦点。

## 6. 图片与文件

- 使用官方 FileHandler 模式统一 paste/drop；上传由 runtime 注入。
- MIME、数量和大小限制由共享策略与宿主能力共同决定。
- 上传占位记录稳定 upload ID、文件预览、进度、错误和重试信息。
- 上传成功使用 transaction 替换占位，保留当前位置与历史语义。
- 外部 URL 插入必须校验协议，并允许后续替换为托管素材。
- Story 现有照片面板继续可直接调用同一图片插入命令。

## 7. 链接

- Cmd/Ctrl+K、Bubble Menu 和主栏/更多菜单打开同一个 Link Popover。
- 有选区时设置链接；光标位于链接中时编辑现有链接。
- 支持协议补全、危险协议拒绝、复制、打开和移除。
- 选中文本后粘贴单一 URL 可直接创建链接，但不得覆盖文件、故事卡片和媒体嵌入粘贴规则。

## 8. 表格

- 插入入口提供可键盘操作的行列网格和数字输入降级。
- 使用 TableKit 或与当前版本等价的官方表格扩展组合。
- 上下文工具根据 `editor.can()` 启用或禁用命令。
- Tab/Shift+Tab 保留表格导航，不插入普通缩进。
- 窄屏表格允许水平滚动，节点工具使用底部面板。

## 9. 粘贴策略

外部粘贴：

- 保留语义节点、链接和基础 marks。
- 清理字体、字号、颜色、背景、布局和未知 style。
- 未支持结构转为安全段落/文本，不直接注入任意 HTML。

内部粘贴：

- 通过自有 MIME 或 Tiptap JSON 保留完整受支持节点和属性。
- 未知版本进入兼容解析与可观测降级，不静默丢弃。

优先级：文件上传 > 内部结构内容 > 故事链接卡片 > 媒体嵌入 > 选区 URL 成链 > 普通富文本/纯文本。

## 10. 保存状态

共享编辑器接收宿主状态：

- `clean/saved`：已保存，可显示最后保存时间。
- `dirty`：有未保存更改。
- `saving`：保存中。
- `error`：保存失败，提供重试。

编辑器不拥有发布、草稿恢复和持久化实现；Story/Blog 现有自动保存逻辑适配为统一契约。

## 11. AI

- 固定侧栏保留会话、任务进度、Diff、应用和撤销。
- Bubble Menu 提供“针对选区使用 AI”。
- 块菜单提供“针对当前块使用 AI”。
- Slash/插入菜单可提供“打开 AI 写作”，但不与同步块命令混淆排序。
- 快捷入口只展开侧栏并传递上下文，不直接在菜单内执行长任务。
- AI 锁定期间所有编辑命令、粘贴、拖放和宿主外部插入保持禁用。

## 12. 响应式

桌面：精简主栏 + Popover/Dropdown + 轻量 Bubble Menu。

窄屏：

- 主栏命令条横向滚动展示全部命令（含字体/字号）；插入、更多、撤销重做固定常驻。
- 格式菜单仅保留工具栏没有的命令（首字下沉、文字颜色、背景颜色）。
- 插入、格式、表格和节点工具使用底部面板。
- AI 侧栏改为覆盖式面板并处理安全区和软键盘。
- 触控目标至少 44x44 CSS px；不依赖 hover 才能完成操作。

## 13. 内容兼容

- 保留 HTML + JSON 双输出契约，JSON 为结构事实。
- 文档或宿主记录增加 schema version。
- 新 schema 以增量方式加入节点/属性，不复用旧名称表达不同语义。
- 读取旧内容时兼容解析；编辑/保存时运行幂等归一化。
- 对未知节点记录诊断并以可恢复占位或安全降级呈现。
- 建立真实历史文档 fixture，验证编辑态与阅读态一致。

## 14. 实施阶段

1. 基础设施：命令注册表、浮层协调、焦点模型、官方免费 UI primitives 兼容验证。
2. 入口重构：精简主栏、更多菜单、Bubble Menu，迁移现有命令但不改变 schema。
3. 块能力：免费 Slash Menu、块菜单、统一插入命令、历史语义。
4. 节点体验：文件上传占位、链接 Popover、表格网格和节点上下文工具。
5. 跨宿主状态：保存状态契约、Story/Blog 与 Web/Desktop 接入、AI 上下文入口。
6. 兼容与质量：粘贴清洗、schema version、历史 fixture、响应式、无障碍和回归测试。

## 15. 非目标

- 实时协作、评论、Tiptap Cloud 和商业 UI Components。
- 完整 Notion 数据库、公式表格或页面级块数据库。
- 本轮重写 AI agent 协议。
- 取消 HTML 输出或立即批量迁移所有历史内容。
