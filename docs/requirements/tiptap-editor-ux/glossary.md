# Tiptap 编辑器体验优化术语表

- 日期：2026-08-04

| 术语 | 定义 |
|---|---|
| 固定工具栏 / Main Toolbar | 编辑器顶部长期可见的通用命令区。 |
| Bubble Menu | 选中文本或节点后，锚定于选区附近显示的上下文工具栏。 |
| Floating Menu | Tiptap 提供的浮动菜单容器；当前项目用于空段落快捷插入。 |
| Slash Menu | 输入 `/` 后出现的可搜索、可分组插入命令菜单。 |
| 块菜单 / Block Menu | 针对当前块提供转换、复制、删除、移动等操作的菜单，通常与拖拽手柄关联。 |
| 节点工具栏 / Node Toolbar | 图片、表格、媒体等节点被选中时显示的专用操作区。 |
| 命令层 / Command Layer | 封装 Tiptap chain/command、可用性判断、焦点恢复和撤销语义的共享操作层。 |
| 语义格式 | 标题、段落、列表、引用、代码块等表达内容结构的格式。 |
| 视觉格式 | 字体、字号、颜色、高亮、对齐等改变视觉表现的格式。 |
| 插入意图 / Insert Intent | 用户希望在当前文档位置创建某类内容块的操作目标。 |
| 上传占位 / Upload Placeholder | 文件上传期间存在于文档中的临时节点或 decoration，承载进度、失败和重试状态。 |
| 原子命令 | 对用户而言应作为一个整体撤销/重做的编辑操作。 |
| Schema | Tiptap/ProseMirror 允许的节点、marks、属性和嵌套规则集合。 |
| NodeView | 自定义节点在编辑态中的 React/DOM 呈现及交互实现。 |
| 官方优先 | 先验证 Tiptap 官方扩展、UI Components、模板与推荐模式，只有产品差异明确时才自定义。 |
| 渐进式块编辑 | 保留传统富文本输入主路径，同时通过 Slash Menu、块手柄和节点上下文工具提供块能力。 |
