# ADR-0001：Web 资源库与 Desktop 云端资源库交互对齐

- 状态：已接受
- 日期：2026-08-04

## 背景

Web 管理端的资源库此前仅复用照片列表和部分相册工作区能力。相册导航项虽已具备右键菜单，但照片卡片、图片预览、右侧信息栏、叙事入口与加载策略仍未与 desktop 云端资源库对齐。

当前 web 端在管理布局初始化时读取全部照片。该策略会让资源库的筛选、预览前后切换和批量操作依赖全量内存数据，且照片规模增长后首屏与筛选响应会退化。

## 决策

以 desktop 云端资源库为交互基准，web 端保留现有管理端视觉语言和已存在的编辑能力。

### 资源库范围

- 对齐相册导航、相册浏览、照片浏览、右键菜单、图片预览、详情栏、批量操作和加载反馈。
- 相册导航项保留打开、编辑、管理照片、发布/取消发布和删除。
- 照片网格与列表都提供同一套右键入口：预览、编辑图片、编辑关联叙事、选择/取消选择、精选切换、展示/隐藏和删除。

### 图片交互

- 单击照片选择并显示右侧信息栏。
- 双击照片或选择右键菜单中的预览，打开全屏图片预览层。
- 预览层在当前筛选结果内支持上一张、下一张、左右方向键、Esc 关闭和加载状态。
- 资源库照片画布支持裁切填充、完整适应和瀑布流三种浏览模式；模式与密度按现有偏好存储机制持久化。
- 现有列表模式可保留给通用照片管理页，但不替代资源库的三种图片浏览模式。

### 叙事入口

- 已有关联叙事的照片，右键“编辑关联叙事”跳转至 `/admin/logs?editStory=<storyId>` 的完整叙事编辑器。
- 尚未关联叙事的照片，打开图片编辑抽屉的叙事标签；只有用户保存创建后才产生叙事记录。后续操作可直达完整编辑器。

### 详情和操作反馈

- 右侧信息栏提供大图预览、编辑图片、编辑关联叙事、精选、展示/隐藏、删除，以及 ID、路径、资源 URL 和色彩数据的查看或复制。
- 照片卡片显示精选、隐藏、胶片等状态；删除或更新进行中时锁定受影响卡片。
- 批量操作围绕当前查询结果工作，保留现有更细粒度的批处理能力，并补齐 desktop 的直接展示/隐藏操作。

### 加载边界

- 资源库照片查询采用分页加载、滚动补页、筛选变化重置和当前查询结果缓存。
- 资源库不再依赖管理布局中的全量照片读取；全局数据仍可服务其他管理页面，但资源库自行维护其分页数据与请求失效控制。

## 不变量

- 所有修改仍使用现有认证、照片、相册和叙事 API，不新增后端协议。
- 右键打开菜单不会改变当前筛选、选择或详情栏状态，除非用户执行菜单动作。
- 删除、展示状态和精选状态失败时必须给出错误反馈并恢复可操作状态。
- 预览、编辑和叙事跳转只作用于当前照片，筛选和多选状态保持可预测。
- 现有 `/admin/photos` 通用管理页不能因资源库专用交互迁移而退化。

## 后果

- 需要从共享照片列表中拆出或参数化资源库专用的照片工作区，避免把资源库的数据流和交互强加给通用管理页。
- 管理上下文需要提供显式的照片编辑入口，以便从资源库直接打开信息或叙事标签。
- 需要新增可复用的全屏预览层、照片右键菜单和分页查询状态管理。
- 需要为快速滚动、筛选切换、预览导航、批量操作和关联叙事不存在的情况增加回归验证。
