# Web 资源库对齐术语表

| 术语 | 定义 |
| --- | --- |
| 资源库 | Web 管理端 `/admin/library` 的云端照片、相册和胶卷工作区。 |
| 云端资源库 | Desktop 端 `CloudLibraryPage` 提供的云端照片管理体验，本轮交互基准。 |
| 通用照片管理页 | Web 管理端 `/admin/photos`，保留其现有列表与批量管理职责。 |
| 资源库照片工作区 | 资源库中负责分页查询、浏览模式、卡片交互、选择和批量操作的中间区域。 |
| 当前查询结果 | 当前筛选、搜索、排序与分页组合下已加载的照片顺序；预览前后切换和范围选择只在此集合内进行。 |
| 裁切填充 | 以固定卡片比例裁切缩略图并填满卡片的浏览模式。 |
| 完整适应 | 保持图片完整可见并在卡片内留出必要留白的浏览模式。 |
| 瀑布流 | 按原始宽高比排列的多列图片浏览模式。 |
| 图片编辑抽屉 | `PhotoDetailPanel`，提供照片信息与关联叙事编辑；无关联叙事时的安全创建入口。 |
| 完整叙事编辑器 | `/admin/logs?editStory=<storyId>` 中的叙事编辑界面。 |
| 关联叙事 | 包含当前照片的 `StoryDto`。 |
| 右键菜单 | 在相册导航项或照片卡片上打开的上下文菜单；打开本身不改变选择或筛选。 |
| 全屏预览层 | 用于查看当前照片并在当前查询结果中前后导航的覆盖层。 |
