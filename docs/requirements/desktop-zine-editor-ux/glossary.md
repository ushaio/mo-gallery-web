# Desktop Zine 编辑器交互术语表

- 日期：2026-08-03

| 术语 | 定义 |
|---|---|
| 跨页 / Spread | 左右两页组成的一个编辑画布，拥有统一宽高和书脊位置。 |
| 跨页坐标 | 以整个 spread 左上角为原点的 mm 坐标，所有对象编辑的唯一事实坐标。 |
| 槽位 / Slot | 画布中的图片或文字对象，不再隐含“只能属于单页”的编辑约束。 |
| 选择态 | 对象被单击选中，显示控制框和上下文工具，但尚未进入内容编辑。 |
| 几何手势 | 移动、缩放或旋转对象外框的连续指针操作。 |
| 图片裁切态 | 双击图片后，只调整图片内层的平移和缩放，外框几何保持不变。 |
| 文字编辑态 | 双击文字后进入可输入状态，点击外部或 Esc 提交并退出。 |
| 草稿几何 | 手势期间仅存在于组件/DOM 层的临时几何，不立即写入项目。 |
| 提交 | 手势结束时将草稿结果写入项目，并产生一次历史记录。 |
| 轻量智能吸附 | 对页面边缘、中心、书脊和安全边距进行吸附，同时显示短暂参考线。 |
| 自由跨页 | 对象可覆盖左右页、书脊和出血区；导出时按页面/跨页裁切显示。 |
| 跟手 | 指针移动与对象视觉变化基本同步，无明显一拍延迟、抖动、回弹或控制框残影。 |
| 保留现场 | 错误发生后保留当前布局和用户输入，只标记局部失败并提供恢复动作。 |
