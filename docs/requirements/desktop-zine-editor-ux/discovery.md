# Desktop Zine 编辑器交互优化 Discovery

- 状态：访谈基线
- 日期：2026-08-03
- 范围：Desktop Wails + React Zine 编辑器
- 目标：先稳定核心编辑交互，再扩展高级排版能力

## 1. 已确认目标

1. 产品定位为轻量 Canva：默认简单直观，操作反馈即时，避免暴露过多专业参数。
2. 第一阶段优先解决拖动、缩放、旋转不跟手，以及选择/编辑状态混乱。
3. 手势期间只做视觉实时预览；松手后一次性提交状态、历史记录和自动保存。
4. 单击选中，双击进入专用编辑态：文字编辑或图片裁切。
5. 对象可在整个跨页画布中自由移动，可跨越书脊；不做多选、组合和批量移动。
6. 使用轻量智能吸附：页面边缘、中心、书脊、安全边距，并显示参考线。
7. 错误处理优先保留现场、局部降级，并提供重试/替换，不阻塞整个编辑器。

## 2. 当前实现中观察到的根因

- `SlotView` 同时维护 React 几何、DOM 临时样式和 Moveable 测量结果，容易出现控制框残影和视觉回弹。
- `updateSlot` 在每次手势结束时记录历史，但拖动期间的几何来源仍依赖单页坐标与像素 delta 的转换。
- 数据模型使用 `page + x/y` 表达槽位位置，与“自由跨页对象”语义冲突。
- 画布当前仅实现 Ctrl/Cmd+滚轮缩放，普通滚轮没有稳定的平移语义，且缩放中心未定义为指针位置。
- 图片槽目前只有内层 transform 数据，缺少清晰的裁切编辑态和完成/取消边界。
- 模板入口实际是新增模板跨页，不是当前跨页的模板替换；命名容易造成预期偏差。

## 3. 第一阶段不做

- 多选、组合、锁定、图层面板。
- 自动排版和照片书向导。
- 完整印刷级裁切、滤镜、翻转和复杂图片编辑。
- 跨功能素材统一选择器。
- 通过实时写入 Zustand/IndexedDB 实现拖动同步。

## 4. 待实现的核心体验

- 选择态、移动态、缩放态、旋转态、图片裁切态、文字编辑态之间互斥且可预测。
- 所有手势使用统一的跨页坐标系；屏幕像素只作为渲染层临时量。
- 手势开始捕获快照，手势期间只更新本地 draft geometry，手势结束一次性提交。
- 松手时统一做边界钳制、吸附、历史入栈和自动保存调度。
- 画布支持滚轮平移、Ctrl/Cmd+滚轮以指针为中心缩放、空格拖动画布。
