# Desktop Zine 编辑器交互验收矩阵

- 日期：2026-08-03

| 场景 | 预期结果 |
|---|---|
| 单击图片/文字 | 只选中对象，控制框与对象同帧出现，无进入输入态。 |
| 双击文字 | 进入文字编辑，光标可输入；点击外部或 Esc 提交并退出。 |
| 双击图片 | 进入图片裁切态；外框不移动，图片可平移/缩放，支持重置。 |
| 拖动对象 | 内容与指针实时同步；松手后只产生一个历史步骤。 |
| 缩放对象 | 默认自由缩放；松手后尺寸稳定，不回弹、不残留旧控制框。 |
| 旋转对象 | 旋转实时同步；接近 0/45/90 度时轻量吸附并显示参考反馈。 |
| 跨过书脊 | 对象不跳变，可成为单一跨页对象；导出和缩略图保持一致。 |
| 拖入出血区 | 允许对象进入出血区；不破坏安全边距提示和导出裁切。 |
| 普通滚轮 | 画布平移，不改变对象或页面缩放。 |
| Ctrl/Cmd+滚轮 | 以指针位置为中心缩放，指针下内容保持稳定。 |
| 空格拖动 | 可平移画布，不触发对象移动。 |
| 连续撤销 | 一次撤销还原一次完整手势，不出现半步几何状态。 |
| 保存失败 | 保留布局，顶栏显示未保存/失败状态，可重试。 |
| 图片加载失败 | 槽位保留，显示局部占位和替换/重试入口。 |
| 取消文字编辑 | Esc 提交文字内容并退出编辑态。 |
| 取消图片裁切 | Esc 丢弃本次裁切草稿，恢复进入裁切态前的构图。 |
| 点击外部结束编辑 | 文字编辑和图片裁切均提交当前内容并退出。 |
| 画布缩放/窗口调整 | 控制框、对象和参考线重新测量后保持一致。 |

## 自动化入口

- `cd desktop/frontend && npm run test:zine`
- 手势管线：`src/lib/zine/gesture-session.test.ts`
- 图片裁切：`src/lib/zine/crop-session.test.ts`
- 跨页迁移：`src/lib/zine/geometry.test.ts`
- 缩放中心：`src/components/zine/SpreadCanvas.test.ts`
- 撤销粒度：`src/store/zine-history.test.ts`
- Direct Edit：`src/lib/zine/zine-direct-edit-host.test.ts`
