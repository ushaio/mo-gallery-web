## 1. 环境矩阵

| 环境 | 必测内容 | 通过条件 |
|---|---|---|
| Windows 10 x64 VM | 安装包、资源库生命周期、普通格式、单实例 | 无开发工具/额外 codec 也能运行 |
| Windows 11 x64 VM | 同上、WebView、缩放、文件关联 | 行为与 Windows 10 一致 |
| NTFS 本机磁盘 | 建库、扫描、改名、移动、回收、备份 | 路径和锁行为正确 |
| exFAT 直连外接盘 | 建库、扫描、断开、重连、迁移 | 断开进入 suspended，重连校准 |
| 125%/150% 显示缩放 | 三栏工作台、网格、危险确认 | 无文本/按钮/详情重叠 |
| 明暗主题、中英文 | 所有页面状态和错误 | 关键动作可理解，术语一致 |

| ID | 场景 | 结果 |
|---|---|---|
| LIB-01 | 创建空目录资源库 | 生成有效 `library.json`、SQLite 与保留目录 |
| LIB-02 | 初始化已有目录 | 原文件不移动，基础库成功后后台扫描 |
| LIB-03 | 打开普通目录 | 拒绝隐式初始化，提示明确 |
| LIB-04 | 库父路径/后代路径创建库 | 拒绝嵌套，包括 junction/reparse point 间接嵌套 |
| LIB-05 | 库整体移动后从新路径打开 | 资产路径和组织数据保持 |
| LIB-06 | 未知/损坏清单 | 拒绝写入，不覆盖原内容 |
| LIB-07 | 第二实例启动 | 激活已有窗口，不创建可写第二实例 |
| LIB-08 | 另一进程/机器持锁 | 拒绝打开，显示锁冲突 |

| SEC-04 | 切库后访问旧 URL | 旧 session/缓存能力失效 |

## 4. 文件命令与恢复

| ID | 场景 | 结果 |
|---|---|---|
| OPS-00 | 尚无导入偏好时首次导入 | 提示选择复制或移动；取消则不导入、不保存偏好；确认后保存应用级偏好，设置页可修改 |
| OPS-01 | 按复制/移动偏好导入到根、当前目录或具体文件夹 | 库内文件在正确目标建档；复制时库外源文件保留，移动时安全完成后移除库外源文件 |
| OPS-02 | 跨卷移动导入中断 | 未验证目标复制成功前不删除源文件 |
| OPS-03 | 应用内改名/移动资产 | 保留资产 ID、标签、集合和属性 |
| OPS-04 | 创建/改名/移动真实文件夹 | 后代资产路径批量更新且身份保留 |
| OPS-05 | 目标存在同名文件 | 可自动改名/跳过/取消，永不覆盖 |
| OPS-06 | 预检后外部创建冲突 | 执行阶段重新校验，受影响项失败 |
| OPS-07 | 操作各阶段强制退出 | 开库发现 operation，重放或 repair_required |
| OPS-08 | 删除单资产 | 默认进入库回收站，可恢复 |
| OPS-09 | 删除非空文件夹 | 完整目录树回收，分别披露资产与其他文件 |
| OPS-10 | 恢复目标冲突 | 不覆盖，支持改顶层名或取消 |
| OPS-11 | 永久删除 | 二次确认，清理关系与缓存，不承诺可恢复 |
| OPS-12 | 正常可用资产的操作菜单/API | 不提供只删索引的“移除出库”；文件仍在库内时扫描后仍受管理 |
| OPS-13 | 文件已被系统文件资源管理器移出或删除 | 资产成为 missing；显式“移除失联记录”只清理索引和组织关系，不声称删除文件 |
| OPS-14 | 删除复制导入的资产 | 只将库内副本移入资源库回收站，库外源文件不受影响 |
| OPS-15 | 删除移动导入的资产 | 将已经进入库内的真实文件移入资源库回收站，并可恢复 |

## 8. 证据要求

每个通过项至少保留一种证据：自动测试结果、结构化日志、性能报告或人工截图。性能结果必须记录：Windows 版本、CPU/RAM、盘类型、文件系统、库项数、照片大小分布、冷/热缓存和应用版本。私有 RAW/HEIC 样本不得提交，但要记录本地样本清单与验证日期。
