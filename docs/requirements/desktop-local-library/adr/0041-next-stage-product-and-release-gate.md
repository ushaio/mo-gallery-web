# ADR-0041：下一阶段产品定位与发布门槛

- 状态：已接受
- 日期：2026-08-02
- 关联：ADR-0017、ADR-0021、ADR-0038、ADR-0039、ADR-0040

## 背景

本地资源库 MVP 的核心功能已经落地，但正式发布仍缺少真实介质、10 万项性能、Windows 环境、故障恢复和可访问性证据。下一阶段如果继续叠加智能能力或跨模块能力，会放大未验证基础设施的风险。

## 决策

下一阶段以“专业照片资产管理”为产品定位，优先完成可靠性与发布验收，不以智能搜索、跨库协作或线上模块扩展作为主线。

下一阶段必须同时完成两类工作：

1. **发布 Gate**：补齐真实样本、性能、安全、故障注入、文件系统、Wails production build 和 Windows 10/11 x64 验收证据。
2. **专业工作流收尾**：在不改变资源库边界和资产身份规则的前提下，完善照片查看、批量整理、查询体验和真实目录浏览。

## 范围优先级

P0：

- Windows 10/11 x64 干净环境安装与启动；
- NTFS 与直连 exFAT 外接盘的建库、扫描、断开、重连和迁移；
- 10 万项性能基准、内存/CPU/缓存体积记录；
- watcher 风暴、漏事件、SQLite busy/corrupt/disk full、强制退出和操作恢复；
- 目录穿越、链接逃逸、旧 session、伪造资产 ID 和危险确认安全测试；
- 已承诺媒体格式的真实样本矩阵；
- 键盘、缩放、明暗主题、中英文和 reduced motion 验收。

P1：

- 文件管理器混合浏览语义；
- 原图查看的缩放、100%、拖动和连续浏览收尾；
- 批量整理、筛选摘要、快捷键和详情面板一致性；
- 通用文件操作计划、冲突策略和逐项恢复日志。

P2：

- 重复内容检测；
- RAW+JPEG 合并显示；
- 智能集合、OCR、人脸/物体识别、相似搜索；
- Zine、故事、AI 和跨库能力。

## 发布规则

- 未完成 P0 证据前，不宣称完整 HEIC/AVIF/RAW 支持、NAS/云目录支持或 macOS 发布支持。
- P1 可以并行开发，但在 P0 证据齐全前不得作为正式版本发布；不得绕过文件安全和资产身份不变量。
- P2 新能力必须单独进行需求定界和技术验证，不自动并入本阶段发布承诺。

## 后果

- 下一阶段优先降低数据丢失、性能和发布环境风险，而不是扩大功能清单。
- 专业照片管理体验仍持续完善，但所有 UI 能力必须服务于大库浏览、筛选、预览和整理。
- 现有 MVP 计划的 Phase 0、Phase 4、Phase 6 成为下一阶段主要工作来源。
