# ADR-0032：应用内真实文件夹管理

- 状态：已接受
- 日期：2026-07-30

## 决策

MVP 支持真实文件夹的创建、重命名和资源库内部移动。

- 应用内操作保留文件夹及全部后代资产 ID、标签、集合等组织数据；
- 创建名称须通过 Windows 保留名称、重复名称和路径长度校验；
- 移动/改名前预检完整目标子树，路径冲突绝不覆盖；
- 禁止移出库根、移入 `.mo-gallery`、移入自身后代、形成目录循环或嵌套资源库；
- 长任务显示进度，并阻止同一路径上的冲突写操作；
- 应用主动更新索引，自身产生的 watcher 事件须去重；
- 文件夹删除语义由 ADR-0033 决定。

## 一致性

文件系统与 SQLite 不能共享真正的 ACID 事务。“原子更新”是用户可观察语义，实现采用：完整预检、持久化操作意图、磁盘操作、SQLite 事务、完成标记、开库修复。磁盘失败不提交索引；磁盘成功但数据库失败时进入 `repair_required`，不能误判为普通外部移动。
