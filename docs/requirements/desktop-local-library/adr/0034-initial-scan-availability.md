# ADR-0034：首次扫描期间的资源库可用性

- 状态：已接受
- 日期：2026-07-30

## 决策

基础资源库创建成功后立即进入工作台，全量媒体扫描在后台渐进执行。

### 原子性边界

基础初始化只负责校验、在临时目录创建清单和空数据库并提交有效 `.mo-gallery`。全量扫描是独立、可中断和可续跑的任务；扫描中断不回滚有效资源库及已建档资产。

### 扫描期间

- 可浏览、预览、编辑组织字段、导入及执行受约束文件操作；
- 搜索、筛选、计数和全库批量操作必须显示“结果可能不完整”；
- 支持暂停、继续、取消和关闭应用后从检查点续扫；取消不删除已建档资产；
- 报告当前阶段、已检查、已建档、已跳过和失败数；总数未知时不伪造百分比；
- 扫描、watcher 和导入共享按规范化相对路径幂等的建档管线；
- 文件命令优先并通过路径锁避免读取中间状态；
- 单文件失败可重试且不阻断全库。

`LibraryState` 与 `ScanJobState` 分离；有效资源库可同时处于扫描中、暂停或待校准。
