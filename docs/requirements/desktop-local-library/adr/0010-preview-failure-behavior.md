# ADR-0010：受支持格式无法生成预览时的行为

- 状态：已接受
- 日期：2026-07-30

## 背景

RAW、HEIC 和 TIFF 即使扩展名受支持，也可能因厂商变体、文件损坏、缺少内嵌预览或解码器限制而无法生成缩略图。必须决定该文件是否仍作为资产出现在资源库中。

## 候选方案

### A. 仍建立资产，以占位图显示（建议）

保存路径、文件名、大小、修改时间以及能读取到的元数据；资产状态标记为 `preview_unavailable`，网格中显示格式占位图和失败提示。用户仍可移动、重命名、加入集合、添加标签和在系统中打开原文件，也可手动重试预览。

优点：资源库不会静默漏掉照片，特别适合厂商 RAW 变体；用户能看到并处理失败项。

代价：界面中会出现无法预览的资产，需要失败筛选、重试和错误信息。

### B. 只有成功生成预览才建立资产

无法预览的文件记入扫描日志，但不出现在照片网格。

优点：网格中每个资产都可查看。

代价：用户可能误以为文件不存在；格式支持缺口被隐藏；标签和整理流程无法覆盖这些文件。

## 建议的不变量

- 解码失败不得移动、删除或修改原文件；
- 单个坏文件不能中断整个扫描；
- 重试必须幂等，成功后更新同一资产，不能创建重复记录；
- 错误详情写入库内索引，日志中不得包含不必要的照片内容。

## 决策

采用 **方案 A：仍建立资产，以占位图显示**。

- 受支持格式无法生成预览时仍创建资产记录；
- 状态标记为 `preview_unavailable`，保存路径、文件信息、已成功读取的元数据和失败原因；
- 网格显示格式占位图，不把解码失败误报为文件失联；
- 资产仍可添加标签/集合、应用内改名/移动、在系统程序中打开；
- 支持按预览失败状态筛选并手动重试；
- 解码能力升级或重试成功后更新同一资产并生成缩略图。

## 后果

- 单个损坏或不兼容文件不能中断扫描队列；
- 预览生成状态与资产索引状态需要分开建模；
- 失败原因需面向用户归类，底层错误保留在诊断信息中；
- 解码失败不得修改、移动或删除原文件。
