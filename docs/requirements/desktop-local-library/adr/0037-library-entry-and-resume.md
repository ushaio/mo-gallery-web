# ADR-0037：本地资源库入口与最近库恢复

- 状态：已接受
- 日期：2026-07-30

## 决策

仅当用户点击全局侧栏“本地资源库”时，尝试恢复上次使用的资源库。Desktop 启动本身不无条件访问本地库。

### 入口

- 入口仍在现有登录与 `ProtectedRoute` 后；
- 点击后读取最近库定位信息，校验真实路径、清单、格式版本、库 ID 与写锁；
- 打开成功后才启动 SQLite、watcher、校准与预览任务；
- 上次库不可用、卷未连接或锁冲突时停留在入口页，不影响线上功能；
- 提供重试、选择其他最近库和从磁盘打开；
- 普通目录不会因最近路径命中而被自动初始化。

### 无当前库

显示创建空资源库、初始化已有照片目录、打开已有资源库三个动作。最近条目只保存名称、路径、最后打开时间与可用性；移除记录不删除磁盘资源库。

### 切换与关闭

工作台提供库切换器和“关闭当前库”。切换前停止扫描、watcher 和预览，等待文件命令到安全点，保存扫描检查点，关闭数据库并释放写锁。关闭库不退出 Desktop，也不登出账号。
