# ADR-0030：路径不变但文件内容被外部替换

- 状态：已接受
- 日期：2026-07-30

## 背景

用户可能在 Photoshop、Capture One 或系统工具中原地覆盖资源库文件。相对路径保持不变，但尺寸、文件大小、EXIF、修改时间和像素内容发生变化。由于资产身份绑定路径，需要决定哪些数据保留、哪些数据重新生成。

## 候选方案

### A. 保留资产身份和用户整理数据，刷新技术数据（建议）

- 文件监听或校准发现同一路径的大小/修改时间变化后，将资产标记为待重新索引；
- 保留资产 ID、集合、标签、评分、颜色、收藏、显示标题和备注；
- 重新读取格式、尺寸、文件大小、修改时间、EXIF/GPS 和预览能力；
- 使旧缩略图/屏幕预览失效，并生成新版本；
- 正在查看时先保留旧预览并显示“文件已更新”，新预览完成后替换；
- 后续重复检测阶段使旧内容哈希失效并重新排队。

优点：符合“同一路径仍是同一资产”的既定身份规则，外部编辑不会丢失整理成果。

代价：如果用户把完全无关的照片覆盖到相同路径，它仍继承原有标签和集合；这是路径身份模型的明确结果。

### B. 内容变化就创建新资产

优点：不会让无关内容继承旧标签。

代价：需要内容身份判断，与已选择的路径身份冲突；正常外部修图也会丢失整理成果。

## 建议的不变量

- 检测变化不依赖完整 SHA-256，可先使用大小、mtime 和平台文件信息；
- 文件仍在写入时采用稳定窗口/重试，不能读取半写入内容并永久标记损坏；
- 刷新失败保留旧组织数据，并显示技术数据/预览待处理状态；
- 不保存旧版本原文件，资源库不是版本控制系统；
- 应用不会自动撤销外部覆盖。

## 决策

采用 **方案 A：保留资产身份和用户整理数据，刷新技术数据**。

- 同一相对路径的文件大小、修改时间或平台文件信息变化后，原资产进入待重新索引状态；
- 保留资产 ID、集合、标签、评分、颜色、收藏、显示标题和备注；
- 重新读取格式、尺寸、文件大小、修改时间、EXIF/GPS 与预览能力；
- 旧缩略图和屏幕预览失效，新版本完成前可暂时显示旧图并标注“文件已更新”；
- 后续重复检测阶段使旧内容哈希失效并重新排队；
- 如果完全无关的内容覆盖到同一路径，也继承原路径资产的组织数据，这是路径身份模型的明确结果。

## 后果

- 监听器需等待文件大小/修改时间进入稳定窗口，再提取元数据和预览；
- 刷新失败时保留用户整理数据，技术状态标记为待处理/失败；
- 资源库不保存旧原文件版本，也不提供撤销外部覆盖；
- 应用内不得把外部内容更新误报为新资产。
