# ADR-0042：文件管理器式混合浏览视图

- 状态：已接受
- 日期：2026-08-02
- 关联：ADR-0021、ADR-0022、ADR-0032、ADR-0037

## 背景

资源库的真实文件夹是磁盘目录，不只是照片筛选条件。当前目录可能没有照片、只有子文件夹，或者用户开启“不显示子文件夹照片”后照片结果为空。此时仅显示照片空状态会阻断目录导航，与用户对文件管理器的预期不一致。

## 决策

在真实文件夹浏览视图中，中央浏览区域采用文件管理器式混合视图：

1. 显示当前目录的直接子文件夹；
2. 显示当前查询范围内的照片资产；
3. 子文件夹排在照片之前；
4. 双击子文件夹进入该目录；键盘 Enter 提供等价操作；
5. 当前目录和子文件夹共享同一虚拟网格，但文件夹不参与照片选择、预览、上传和批量资产操作。

当视图处于收藏、集合、标签、失联、回收站、关键词搜索或结构化筛选状态时，不显示物理文件夹卡片，避免把目录项混入逻辑查询结果。

## 交互约束

- 文件夹卡片显示文件夹图标、名称和可选的直接资产数量；
- 目录切换后滚动位置回到顶部；
- 空状态只有在“照片和直接子文件夹都为空”时显示；
- 文件夹仍可通过左侧目录树进行单击进入、展开/折叠和上下文操作；
- 拖放库外文件的目标仍以真实文件夹为准，逻辑目标不因此获得接收外部文件的能力；
- 搜索和结构化筛选继续只作用于照片资产，不对文件夹名称做隐式搜索。

## 后果

- 空目录、只有子目录的目录和隐藏子目录照片的场景都可继续浏览；
- 递归照片视图中会同时出现子文件夹和照片，符合文件管理器混合浏览语义；
- 虚拟网格需要以“文件夹或资产”的统一条目计算行数和滚动高度；
- 文件夹卡片不能复用照片选择语义，必须保持类型边界清晰。
