# ADR-0033：非空真实文件夹删除

- 状态：已接受
- 日期：2026-07-30

## 决策

删除非空真实文件夹时，默认将完整目录树作为一个批次移入资源库回收站。

### 删除

- 删除前递归统计已索引资产数、其他文件数、目录数和总大小；
- 确认框必须分别披露“受管理资产”和“其他文件”；
- 完整目录树移动到 `.mo-gallery/trash/<trash-entry-id>/payload/`；
- 已索引资产保留 ID 与组织数据并进入回收站状态；
- 未索引、不支持和隐藏文件随目录移动，但不自动变成资产；
- 批次整体提交或进入可修复状态，不能将部分结果报告为全部成功；
- 永久删除是非默认危险选项，并执行二次确认。

### 恢复

- 默认恢复原父目录和名称；原父目录不存在时可选择资源库内其他位置；
- 恢复前预检完整目标树，任一冲突都不覆盖；用户须更改顶层名称或取消；
- 已索引资产恢复原 ID 与组织数据；其他文件只恢复到磁盘，支持格式由校准管线决定是否建档。

文件夹回收站条目是目录树恢复单元，不是若干照片删除记录的简单集合。
