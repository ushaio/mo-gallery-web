# ADR-0044：V1.1 发布证据、私有样本与性能基准

- 状态：已接受
- 日期：2026-08-02
- 关联：ADR-0041、ADR-0043、ADR-0017、ADR-0038、ADR-0039、ADR-0040

## 决策

V1.1 正式发布平台保持为 Windows 10/11 x64。macOS、NAS、云同步目录和其他平台不进入本次正式验收承诺。

### 私有媒体样本

真实 RAW/HEIC/TIFF/AVIF 等样本不提交仓库。仓库提交：

- `desktop/testdata/local-library/README.md` 样本规范；
- 样本生成器或导入工具；
- 本地样本清单模板；
- 格式、来源、机型、授权、预期尺寸/方向/预览能力和 SHA-256 记录格式；
- 测试报告中明确“已验证/未验证”，不得用缺失样本推导通过。

验收机保留私有样本，报告记录样本清单版本和结果摘要，不上传原文件。

### 性能基准

10 万项基准使用混合真实照片库模型，至少覆盖不同尺寸、目录深度、EXIF 完整度、预览状态、标签/集合关系和失联/失败比例。报告必须记录硬件、Windows 版本、磁盘类型、文件系统、冷/暖缓存和应用版本。

### 故障注入顺序

P0 第一批优先验证文件操作恢复：

1. 计划确认后强制退出；
2. 磁盘步骤成功、SQLite 提交失败；
3. SQLite 已提交、后续清理失败；
4. 外部竞态造成目标冲突；
5. 重开后重放 operation 或进入 `repair_required`；
6. 逐项结果、原文件路径和资产身份不变量保持可诊断。

随后再覆盖卷断开、数据库/迁移和 watcher 一致性故障。

## 后果

- 发布证据可在不提交私有照片的前提下复现和审计；
- 性能指标不再只代表空索引或纯缩略图压力；
- 文件操作恢复成为 P0 的第一条故障注入链路；
- 缺少真实样本或硬件时，功能保持“未验证”状态，不扩大正式支持范围。
