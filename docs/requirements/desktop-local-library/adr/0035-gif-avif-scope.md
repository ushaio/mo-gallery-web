# ADR-0035：GIF 与 AVIF 的首期支持范围

- 状态：已接受（修订方案 B）
- 日期：2026-07-30

## 决策

GIF 与 AVIF 使用不同的 MVP 语义。

### GIF

- 建立普通本地资产；
- 网格只显示静态首帧，不自动播放；
- 右侧或大图预览播放原 GIF，并提供播放/暂停；
- 切换资产或窗口不可见时停止播放；尊重“减少动态效果”，启用时默认暂停；
- 记录 `is_animated`，帧数与时长可在无法可靠提取时为空。

### AVIF

- 正式支持静态单帧 AVIF 的索引、缩略图与预览；
- 动画/多帧 AVIF 不承诺播放，可建档并标记“动画 AVIF 暂不支持”或 `preview_unavailable`；
- 未经真实样本验证，不承诺完整 HDR/高位深色彩显示。

### 安全与性能

- 原文件经受资源库边界校验的媒体接口读取，不开放任意 `file://`；
- 缩略图缓存只保存静态派生图；
- 文件头与扩展名共同识别格式；
- 畸形或超大动画受像素、帧数、内存和超时限制；单文件失败不阻断扫描。
