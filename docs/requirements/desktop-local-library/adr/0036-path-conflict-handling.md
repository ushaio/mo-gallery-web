# ADR-0036：应用内路径冲突处理

- 状态：已接受
- 日期：2026-07-30

## 决策

目标路径冲突时显示处理界面，允许逐项选择或应用到本次所有同类冲突。

可选策略：

- **自动重命名**：在扩展名前追加编号，例如 `IMG_001 (1).JPG`；
- **跳过**：源文件和资产路径保持不变；
- **取消操作**：仅在批次开始前取消；
- **应用到本次所有冲突**：不保存为全局偏好。

不提供覆盖/替换目标文件选项。

### 批量语义

- 执行前尽可能枚举全部计划项并集中展示冲突；
- 用户确认后逐项可恢复执行，不承诺跨多文件的文件系统全有或全无事务；
- 成功项保留结果，跳过与失败项留在原处；
- 最终分别汇总成功、自动改名、跳过和失败，并可查看原因；
- 预检后出现外部竞态时执行阶段再次校验，只将受影响项标记失败；
- 文件夹移动必须提前展开后代冲突，不能移动半个目录树后再询问。

自动名称须同时对磁盘现状和当前批次唯一，并符合目标文件系统大小写、保留名称与路径长度规则。后端返回逐项结果，而不是单一布尔值。
