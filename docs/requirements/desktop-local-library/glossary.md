# Desktop 本地资源库：领域词汇表

- 状态：核心领域词汇已收敛
- 规则：同一个概念只使用一个规范名称；如后续决策变更，以最新 ADR 为准并同步更新本表。

| 术语 | 英文/代码候选 | 定义 | 不等同于 |
|---|---|---|---|
| 本地资源库 | Local Library | Desktop 中用于索引和组织本机照片的产品模块/限界上下文。 | 线上图库、磁盘上的单个文件夹 |
| 资源库 | Library | 由一个磁盘根文件夹承载的独立管理单元，包含其目录树内的原文件，以及随库保存的索引和组织信息；可整体迁移后重新打开。 | 相册、任意来源文件夹 |
| 当前资源库 | Active Library | 应用当前唯一打开并提供查询、监听和文件操作的资源库。应用可登记多个库，但同一时间只激活一个。 | 最近资源库列表、跨库聚合工作区 |
| 后台校准 | Background Reconciliation | 打开库后不阻塞已有索引浏览、持续比对磁盘与数据库的后台任务。 | 首屏加载、阻塞式全量扫描 |
| 发现时间 | Discovered At | 资产首次由该资源库索引发现的时间，不等同于拍摄时间或文件修改时间。 | 拍摄时间、导入时间 |
| 最近资源库 | Recent Library | 应用全局配置中的资源库定位记录，只包含路径、最近打开时间等信息，不包含资产和组织数据。 | 资源库数据库 |
| 本地资产 | Local Asset | 被资源库识别并管理的逻辑照片记录。它可引用一个原文件，并拥有独立的标签、评分等组织数据。 | 线上 `Photo`、缩略图文件 |
| 原文件 | Original File | 资源库目录树内承载照片内容的文件；资源库只引用它，不另建全局托管副本。 | 缩略图、预览图、线上对象存储文件 |
| RAW 预览 | RAW Preview | 从相机 RAW 原文件中提取的内嵌 JPEG 预览，用于缩略图和查看；不是对 RAW 数据执行显影。 | RAW 显影结果、修改后的原文件 |
| 屏幕预览 | Screen Preview | 为快速适应窗口查看而按需生成的约 2048px 派生图。 | 原图、RAW 显影 |
| 原图查看 | Original View | 用户显式进入的高倍率只读查看模式；普通图像读取原文件，RAW 显示最高可用内嵌预览并明确标注。 | 默认详情预览、修改原文件 |
| 预览不可用 | Preview Unavailable | 文件已建立资产，但因损坏、厂商变体或缺少可用预览而不能生成缩略图/大图预览；使用占位图且可重试。 | 文件不存在、格式未识别 |
| 资源库根目录 | Library Root | 用户创建或选择为资源库的顶层磁盘文件夹，是允许索引原文件的路径边界。 | 集合/相册、库外任意目录 |
| 应用内导入 | In-app Import | 用户在应用内选择或拖入库外文件，并按已保存的导入方式复制或移动到当前资源库目录后建立索引。 | 系统文件资源管理器复制/移动、上传到线上图库 |
| 本地资源库导入方式 | Local Library Import Mode | 应用内导入库外文件时采用“复制到资源库”或“移动到资源库”的应用级偏好；首次导入必须选择，之后可在“系统设置 → 本地资源库”中修改。 | 单次冲突处理方式、系统文件资源管理器行为 |
| 导入目标 | Import Destination | 库外文件经应用复制或移动后所在的库内真实目录；由资源库根路径、当前浏览文件夹或被拖放命中的文件夹节点决定。 | 集合、标签、搜索条件 |
| 逻辑目标 | Logical Target | 集合、标签或收藏等只修改库内组织数据的拖放目标；不接收尚未入库的外部文件。 | 资源库根目录、真实文件夹 |
| 库内引用 | In-library Reference | 资产记录通过相对路径引用资源库目录树内的原文件；不得长期引用库外散落路径。 | 全局托管副本、库外绝对路径引用 |
| 托管导入 | Managed Import | 将原文件复制或移动到应用管理的资源目录后再索引。 | 引用导入、线上上传 |
| 索引 | Index | 为快速查询保存的路径、文件标识、哈希、尺寸、拍摄信息和组织元数据。 | 原文件内容、缩略图缓存 |
| 一致性扫描 | Reconciliation Scan | 遍历资源库目录树，将磁盘事实与索引进行比对并修复遗漏；在启动或打开资源库时执行。 | 仅依赖文件监听 |
| 文件监听 | File Watch | 应用运行时接收资源库目录变化并触发增量校准的低延迟机制。 | 不会丢事件的事实来源 |
| 资产身份 | Asset Identity | 绑定资源库内相对路径的本地资产标识。应用内改名/移动会原子更新该资产；外部改名/移动则产生失联旧资产和新资产。 | 内容哈希 |
| 缩略图缓存 | Thumbnail Cache | 可再生成的派生图片，用于快速网格浏览。 | 原文件、需要备份的用户组织数据 |
| 资源库保留目录 | Library Metadata Directory | 资源库根目录下的 `.mo-gallery`，保存清单、数据库和缩略图；扫描和监听资产时必须排除。 | 用户照片文件夹 |
| 资源库清单 | Library Manifest | `.mo-gallery/library.json`，保存库 ID、格式版本、创建时间等识别与兼容信息。 | 资产索引数据库 |
| 数据库备份 | Database Backup | `.mo-gallery/backups` 中的 SQLite 一致性快照，保护集合、标签、评分等不可重建数据；不包含原照片。 | 完整照片备份、缩略图缓存 |
| 嵌套资源库 | Nested Library | 一个资源库根目录位于另一个资源库目录树内，包括经符号链接或 junction 间接形成的嵌套；系统禁止该状态。 | 多个彼此独立的资源库 |
| 文件夹 | Folder | 资源库目录树中的真实磁盘目录。应用内移动到文件夹会移动原文件并更新资产路径。 | 集合、标签 |
| 集合 | Collection | 用户在资源库内建立的逻辑分组；一项资产可属于多个集合，加入集合不会移动原文件。 | 磁盘文件夹、线上相册 |
| 集合组 | Collection Group | 用于组织集合和子集合组的逻辑树节点，本身不能直接包含资产。 | 集合、真实文件夹 |
| 标签 | Tag | 用户或系统附加到资产的可检索分类词。 | 文件夹、集合 |
| 评分 | Rating | 资产的 0～5 星整数分级，0 表示未评分；与收藏相互独立。 | 收藏、颜色标记 |
| 颜色标记 | Color Label | 资产的单选视觉分类：无、红、黄、绿、蓝、紫。 | 标签、评分 |
| 收藏 | Favorite | 资产的独立布尔快捷标记，不自动映射为五星评分。 | 评分、集合 |
| 显示标题 | Display Title | 仅存在于资源库数据库中的可选资产标题，不修改磁盘文件名。 | 文件名、应用内重命名 |
| 失联资产 | Missing Asset | 索引存在，但原文件在记录位置不可访问的资产。 | 已删除资产 |
| 重复资产 | Duplicate Asset | 扩展阶段通过完整内容哈希确认字节相同、但路径不同的多个资产；不会自动合并。 | 同名文件、相似照片、资产身份 |
| 删除库内文件 | Delete Library File | 对资源库目录树内真实文件执行删除；默认移入资源库回收站，也可由用户显式选择永久删除。正常资产不支持只删索引而保留库内文件。 | 移除失联记录、删除集合 |
| 资源库回收站 | Library Trash | 位于 `.mo-gallery/trash` 的库内恢复区；默认删除会将文件与资产状态移入此处，并保留组织关系。 | 操作系统回收站、永久删除 |
| 永久删除 | Permanent Delete | 不经过资源库或系统回收站，删除原文件、资产记录、组织关系和缩略图的不可恢复操作。 | 默认删除、移除失联记录 |
| 线上照片 | Remote Photo | 已存在于 MO Gallery 服务端/对象存储中的照片。 | 本地资产 |
| 发布/上传 | Publish / Upload | 将本地资产的原文件送入现有 MO Gallery 上传流程，产生线上照片。 | 本地导入 |
| 当前线上账号 | Active Remote Account | 当前有效登录身份，仅控制功能入口及上传/发布目标，不拥有或锁定本地资源库。 | 资源库所有者、操作系统文件权限 |
| 单实例 | Single Instance | 同一操作系统会话只运行一个 MO Gallery Desktop 实例；再次启动时激活已有窗口。 | 资源库锁 |
| 资源库写锁 | Library Write Lock | 打开资源库时获取的独占底层锁，用于防止另一机器或异常进程同时修改同一可迁移资源库。 | 应用单实例、线上账号锁 |
| 资源库暂停 | Library Suspended | 资源库所在卷断开或严重 I/O 错误时停止全部写入和后台任务的状态；不会把全库资产判定为失联。 | 单个文件失联、关闭资源库 |

| RAW+JPEG 合并显示 | RAW+JPEG Collapsed View | 可选派生展示：同目录同主文件名的 JPEG 为网格主项，关联 RAW 在详情显示而不占普通网格项；两个文件仍是独立资产。 | 物理文件合并、重复资产、组合资产身份 |
| 文件夹删除批次 | Folder Trash Batch | 将完整真实目录树移入资源库回收站形成的恢复单元，可包含已索引资产及不进入索引的其他文件。 | 单个资产删除、仅删除数据库记录 |
| 渐进式首次扫描 | Progressive Initial Scan | 基础资源库创建后在后台可暂停、可续跑地建立媒体索引；库可使用但完成前查询与计数可能不完整。 | 基础初始化事务、阻塞式导入 |
| 动画图片资产 | Animated Image Asset | 原文件含多帧动画的图片资产；GIF 首期网格显示静态首帧，预览区播放原动画。 | 视频、网格动画缩略图、静态 AVIF |
| 路径冲突计划 | Path Conflict Plan | 文件操作执行前的目标路径预检清单，记录冲突及自动改名/跳过策略；执行时仍须再次校验。 | 覆盖文件、跨文件系统事务 |
## 已确定的命名规则

1. 线上 `/photos` 使用“图库/照片库”，Desktop 新模块统一使用“本地资源库”，不得把两者都简称为“资源库”。
2. 线上逻辑分组保留“相册”，本地逻辑分组使用“集合”。
3. 删除类命令必须明确对象和后果，分别使用“移入资源库回收站”“永久删除”“移除失联记录”等文案；不使用无对象的“删除”。
