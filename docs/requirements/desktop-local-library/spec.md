# MO Gallery Desktop 本地资源库 MVP 规格

- 状态：需求基线，可进入技术 spike 与实施
- 日期：2026-07-30
- 首发平台：Windows 10/11 x64
- 依据：`discovery.md`、`domain-model.md`、`adr/0001`～`0037`

## 1. 目标

在 Desktop 新增“本地资源库”，让用户以一个普通磁盘文件夹为边界管理本地照片。原文件位于库目录树内，清单、SQLite 索引和组织数据位于库内 `.mo-gallery`，可随整个文件夹迁移。

参考 Billfish/Pixcall 的资源库概念，但不照搬全部功能。MVP 优先保证文件安全、渐进索引、真实文件夹与逻辑整理、快速浏览、搜索筛选、回收恢复和现有上传集成。

### 成功标准

- 可创建、初始化、打开、关闭和切换资源库；
- 整库移动后重新打开，资产与组织数据不丢失；
- 100,000 项可渐进扫描、分页查询和虚拟化浏览；
- 应用内文件操作保留身份且不覆盖；外部变化最终可校准；
- 默认删除可恢复，永久删除不易误触；
- 支持格式可建档、预览或明确降级；
- 本地资产可送入现有上传队列；
- WebView 不能读取当前库外任意文件。

## 2. 权限与账号

- 入口继续位于现有 `ProtectedRoute`，必须登录；
- 库不绑定线上账号，同一 OS 用户切换账号后仍可打开；
- 当前账号只决定上传目标；
- MVP 不提供离线免登录入口。

## 3. 信息架构

### 3.1 全局入口与欢迎页

- 侧栏新增独立的“本地资源库”，建议路由 `/local-library`；
- 现有 `/photos` 是线上图库，文案不得与新入口混淆；
- 点击入口才尝试恢复上次库，不在 Desktop 启动时无条件打开；
- 无当前库时显示：创建空库、初始化已有照片目录、打开已有库、最近库列表；
- 最近库显示名称、路径、最后打开时间和可用性；移除记录不删除磁盘库；
- 上次库不可用不阻止使用线上功能。

### 3.2 三栏工作台

- 左栏：全部资产、收藏、真实文件夹、集合、标签、失联、预览失败、回收站；
- 中央：当前位置、搜索、筛选、排序、扫描状态、虚拟化网格；
- 右栏：可折叠预览、EXIF、路径、标签、集合、评分、颜色、收藏、标题、备注；
- 顶部：当前库切换器、关闭库、任务状态；
- 多选后右栏进入批量编辑；1024px 宽优先折叠右栏；
- 文件夹与集合使用不同图标、分区、术语及拖放反馈；
- 拖放之外提供菜单和键盘等价操作。

## 4. 资源库生命周期

### 4.1 创建空库

1. 选择一个目录；
2. 校验真实路径、写权限、父库、后代库、链接和已有 `.mo-gallery`；
3. 在临时保留目录创建清单与空数据库；
4. 成功后提交有效 `.mo-gallery`，打开工作台。

禁止直接或经 junction/符号链接形成嵌套库。未知或损坏的 `.mo-gallery` 不自动覆盖。

### 4.2 初始化已有目录

- 预扫描并显示候选受支持文件、其他文件、估算大小和风险；
- 确认后只创建 `.mo-gallery`，不移动照片；
- 基础结构成功后立即进入工作台，后台渐进扫描；
- 初始化失败不留下有效半成品；扫描中断不回滚有效库和已建档资产。

### 4.3 打开、关闭与切换

- “打开已有库”只接受有效清单，普通目录不会被隐式初始化；
- 校验格式版本、库 ID、真实路径、写权限和独占写锁；
- 先显示数据库已有结果，再后台一致性扫描；
- 同时只打开一个库；切库前停止 watcher、扫描和预览，文件命令到安全点，保存检查点，关闭 SQLite 并释放锁；
- 整卷不可用时进入 suspended，不批量制造失联资产。

## 5. 扫描、监听与外部变化

### 5.1 渐进扫描

- 已发现资产持续进入网格；扫描中可浏览、整理、导入及执行受约束文件命令；
- 搜索、筛选、计数和全库批量操作标注“结果可能不完整”；
- 支持暂停、继续、取消及下次断点续扫；
- 显示当前阶段、已检查、已建档、跳过和失败数；总数未知时不伪造百分比；
- 单文件失败可重试且不阻断全库。

### 5.2 watcher 与校准

- 新文件在写入稳定后自动建档；
- 同路径覆盖保留资产 ID 和组织数据，刷新尺寸、EXIF、mtime 与预览；
- 外部删除形成失联资产；
- 外部移动/改名形成失联旧资产和独立新资产，不继承组织数据；
- 文件回到完全相同路径时恢复旧资产；
- watcher 去抖、批处理、幂等；应用自身命令产生的事件不得重复建档；
- watcher 只负责低延迟，开库/启动校准是最终兜底。

## 6. 媒体范围

首期格式：

- JPEG/JPG、PNG、WebP；
- GIF：网格静态首帧，详情/大图预览播放原动画；
- 静态单帧 AVIF；动画 AVIF 可建档但不承诺播放；
- HEIC/HEIF、TIFF；
- CR2/CR3、NEF、ARW、DNG、RAF。

RAW 只提取内嵌 JPEG 与 EXIF，不显影、不修改。受支持格式无法预览时仍建档为 `preview_unavailable`，可组织、移动、重命名、系统打开和重试。视频、Live Photo 不属于 MVP。

正式格式承诺以 Windows 干净环境打包测试和真实机型样本为准；现有 `goexif` 本身不足以完成全部解码矩阵。

## 7. 文件与文件夹操作

### 7.1 库外导入

- 用户首次从应用内导入库外文件时，必须选择“复制到资源库”或“移动到资源库”；取消选择则本次不导入，也不保存默认值；
- 首次确认后保存为应用级“本地资源库导入方式”，后续导入直接沿用；用户可在“系统设置 → 本地资源库”中修改；
- 复制导入保留库外源文件，库内副本成为资源库管理的原文件；移动导入仅在目标文件确认写入成功后移除库外源文件；
- 目标由拖放位置决定：库顶层、当前浏览文件夹或具体文件夹节点；无固定 Inbox；
- 库外文件不能直接拖到集合、标签、收藏或搜索结果，须先入库；
- 复制导入和跨卷移动均先写入目标临时文件，完成完整性校验后原子改名；移动导入在此之前不得删除源文件；
- 复制与移动均不得覆盖目标中的同名文件。

### 7.2 文件夹管理

支持创建、重命名、库内移动文件夹，以及将资产移动到真实文件夹。应用内路径操作保留后代资产 ID 和组织数据。

禁止移出库根、进入 `.mo-gallery`、进入自身后代、形成循环或嵌套库。

### 7.3 路径冲突

任何命令均不覆盖目标。预检冲突时可：自动重命名、跳过、执行前取消、应用到本次同类冲突。批量操作允许部分成功，分别汇总成功、自动改名、跳过与失败；跳过/失败项留在原处。文件夹操作必须预先展开后代冲突。

文件系统与 SQLite 无跨系统事务，实现使用预检、持久化操作日志、磁盘步骤、数据库事务与开库修复。

## 8. 组织能力

- **真实文件夹**：对应磁盘目录，移动会改变原文件路径；
- **集合**：逻辑多对多分组，不移动文件；集合组可嵌套但不能直接放资产；
- **标签**：扁平多对多；
- 属性：0～5 星、红/黄/绿/蓝/紫颜色、收藏、显示标题、备注；
- 收藏不等于五星，标题不修改文件名；
- 组织字段只写 `library.db`，不改 EXIF/IPTC，不生成 XMP；
- 支持多选批量编辑标签、集合、评分、颜色和收藏。

## 9. 搜索、筛选、排序

关键词搜索：文件名/路径、标题/备注、标签/集合、相机/镜头。

结构化筛选：文件夹、集合、标签、收藏、评分、颜色、格式、状态、拍摄/发现日期、相机、镜头、ISO、光圈、焦距、方向、尺寸。

排序：拍摄时间、修改时间、发现时间、文件名、大小、评分。不同组 AND，同组多选 OR。Go/SQLite 使用索引、FTS 和稳定 cursor 分页；React 不全量过滤，网格必须虚拟化。

## 10. 预览与原图

- 512px 网格缩略图后台生成并默认长期保留；当前可视项优先；
- 2048px 屏幕预览首次查看生成，可按空间策略清理；
- GIF 网格不播放，预览提供播放/暂停并尊重 reduced motion；
- 默认显示 2048px，双击或“查看原图”进入适应、100%、缩放、拖动和前后切换；
- 普通格式按需读取原文件；RAW 显示最高可用内嵌 JPEG并明确标注；
- 超大图受控解码，不能无界占用 WebView 内存；
- 另提供系统默认程序打开；原图失败不改变资产可用性；
- 所有媒体 URL 由 Go 按资产 ID 解析和校验，不开放任意 `file://`。

## 11. 删除、回收站与失联

- 正常可用资产不提供“只删除索引、文件仍留在库内”的操作；只要文件仍在资源库目录树中，它就继续由资源库管理；
- 默认删除将库内文件移入 `.mo-gallery/trash`，保留 ID 和组织数据，可恢复；复制导入只处理库内副本，库外源文件不受影响；
- 永久删除为非默认危险选项，批量时显示数量与总大小并二次确认；
- 删除非空目录时完整目录树作为一个批次回收，确认框分别显示受管理资产、其他文件、目录数和总大小；
- 未索引/不支持文件随目录移动但不自动建档；
- 默认恢复原路径，原父目录不存在可选库内其他位置；冲突不覆盖，须改顶层名称或取消；
- 外部删除不进入应用回收站，只形成失联；
- 文件在系统文件资源管理器中被删除或移出库后形成失联；失联记录永不自动清理，只能由用户显式“移除失联记录”；
- 数据库备份不能恢复永久删除的照片。

## 12. 上传集成

```text
本地资产 ID -> Go 校验当前库内原文件 -> 现有上传设置
-> PrepareUpload / UploadFile -> 现有上传队列
```

上传只读取原文件，不修改本地库；本地组织字段不自动映射线上字段；本地可预览不代表服务端接受该格式。Zine、故事、AI 助手集成延后。

## 13. 备份、锁、平台

- 每日有数据库变更后保留 7 份一致性备份；schema 升级前保留 3 份；支持立即备份与恢复；
- 备份不包含照片和预览缓存，恢复前停止写任务并备份当前数据库；
- Wails `SingleInstanceLock` 保证 Desktop 单实例，第二次启动激活已有窗口；
- 当前库另持底层独占写锁，冲突时拒绝打开；MVP 无只读多开；
- 正式支持 Windows 10/11 x64、本机 NTFS 和直连外接盘；验证 exFAT；
- 不正式支持 NAS、云同步目录、WebDAV、视频和 macOS 发布。

## 14. 非功能要求

### 性能目标

以记录硬件、盘类型和缓存条件的 100,000 项测试库验证：

- 已有索引首屏目标 2 秒内；
- 常用分页查询目标 P95 小于 300ms；
- 运行时新增稳定 JPEG 目标 3 秒内出现；
- 不创建 100,000 个 DOM 节点，不在网格自动播放 GIF；
- 首次扫描可中断续跑，不计算全库 SHA-256。

### 可靠性与安全

- 崩溃/断电后已提交组织数据不丢失，未完成文件命令可诊断修复；
- 卷断开停止写入；单文件损坏不导致整库打不开；升级失败可恢复；
- 防目录穿越、链接逃逸和 `.mo-gallery` 访问；
- 危险确认默认焦点位于安全动作；
- 图标有可访问名称，颜色不作为唯一信息，GIF 可暂停。

## 15. MVP 验收摘要

- [ ] 创建、初始化、打开、迁移、切库、锁冲突与嵌套库检查通过；
- [ ] 扫描可暂停续跑，运行中/关闭期间新增文件最终出现；
- [ ] 外部删除、改名、同路径覆盖和卷断开符合身份规则；
- [ ] 应用内资产/文件夹移动保留身份，冲突不覆盖，崩溃可修复；
- [ ] 回收站恢复保留组织数据，目录批次包含其他文件，永久删除二次确认；
- [ ] 每个承诺格式用正常、旋转、损坏和大尺寸样本验证；各 RAW 家族用真实机型样本；
- [ ] 100,000 项分页/虚拟化、搜索 AND/OR 语义和性能目标通过；
- [ ] 本地资产进入现有上传队列，数据库备份/恢复和单实例通过；
- [ ] 原图接口不能访问当前库外文件。

## 16. 明确延后

RAW+JPEG 合并显示及组命令、完整重复检测、视频/Live Photo/动画 AVIF 播放、OCR/人脸/物体/语义与相似搜索、智能集合、标签层级、XMP、跨库搜索/拖放、线上字段映射、Zine/故事/AI 集成、NAS/云目录、正式 macOS、只读多开。
