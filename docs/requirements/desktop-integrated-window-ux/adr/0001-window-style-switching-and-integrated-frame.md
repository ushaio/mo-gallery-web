# ADR-0001：窗口风格切换与一体化窗口壳层

- 状态：已接受
- 日期：2026-08-03

## 背景

桌面端支持原生和一体化两种窗口风格。一体化模式通过 Wails 无边框窗口和 React 自绘标题栏实现，但当前标题栏状态表达和边缘反馈不足。

## 决策

1. 保留 `native` 与 `integrated` 两种配置。
2. 窗口风格切换保存后询问用户是否立即重启；确认后由应用自动重启进程生效，取消则在下次启动时生效；不实现伪即时切换。
3. 一体化标题栏读取真实最大化状态，动态切换最大化/还原图标与无障碍名称。
4. 标题栏监听窗口焦点，失焦时降低视觉权重。
5. 一体化窗口使用统一边缘、阴影和标题栏下方的 Toast 偏移，保证系统边界可识别。

## 后果

- 设置页需要持续区分配置风格和当前运行风格。
- 用户切换窗口风格后可选择立即重启应用，也可稍后重启；行为与底层窗口生命周期一致。
- 标题栏成为窗口系统能力的适配层，后续新增控制必须保持拖拽区域与控制区域分离。
