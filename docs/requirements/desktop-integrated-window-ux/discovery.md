# Desktop 一体化窗口体验优化：Discovery

## 目标

优化桌面端一体化窗口的系统感和工作区连续性，重点解决无边框窗口在控制、焦点、最大化状态和边缘识别上的不完整体验。

## 已确认决策

- 范围覆盖窗口壳层、布局联动、设置反馈和状态持久化。
- 主要痛点是系统感不足，而非单纯视觉风格问题。
- 保留 `native` 与 `integrated` 两种窗口风格。
- 窗口风格切换保存后询问用户是否立即重新加载应用进程；确认后立即生效，取消则在下次启动时生效。
- 主要验收尺寸为 `1024x700` 和 `1440x900`。
- 一体化窗口使用自绘标题栏，标题栏承担拖拽、双击最大化/还原和窗口控制。

## 现状问题

- 一体化标题栏始终显示最大化图标，无法表达当前窗口状态。
- 窗口失焦时没有明确的层级变化。
- 无边框窗口缺少稳定的外边缘、阴影和控制区焦点反馈。
- 设置页已有重启提示，但窗口风格语义需要与实际运行时状态保持一致。

## 非目标

- 不在本轮实现跨平台原生标题栏重绘。
- 不修改应用内各页面的业务布局和数据流程。
- 不把原生/一体化风格抽象成可运行时热切换的假状态。
