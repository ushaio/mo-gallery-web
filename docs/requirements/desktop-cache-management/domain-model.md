# Desktop 缓存管理领域模型

- 状态：已收敛
- 日期：2026-08-02

## 聚合与边界

### 应用数据缓存

由 Desktop 前端拥有，可安全失效并在后续页面访问时重新加载。

- 页面运行时状态：当前进程内的概览数据、设备列表、云端照片分页和滚动位置。
- 持久化页面数据：按账号与服务端作用域写入 localStorage 的概览、相册、分类、胶卷、故事和朋友列表。
- CacheStorage：由 MO Gallery 网页功能写入、按当前服务端与账号命名空间隔离、前端可枚举和删除的响应缓存。

不变量：清理应用数据缓存不得删除登录身份、用户设置或服务端数据。

### 本地预览缓存

由本地资源库拥有，位于 `.mo-gallery` 内，可安全删除并从原文件重新生成。

- 屏幕预览：最长边约 2048px，按需生成，受既有空间上限管理。
- 网格缩略图：最长边约 512px，当前版本长期保留，不提供清理命令。

不变量：清理屏幕预览不得删除原文件、索引、集合、标签、评分或缩略图。

### 资源库数据

位于 `.mo-gallery` 内但不属于缓存，包括数据库、清单、备份、回收站和任务状态。只能在“本地资源库 → 存储占用”中作为只读占用展示。

不变量：任何缓存清理命令都不得触及资源库数据。

## 关键计算

```text
应用磁盘缓存 = 持久化页面数据 + CacheStorage
可释放空间 = 应用磁盘缓存 + 本地屏幕预览
运行时缓存 = 页面进程内状态（不计入可释放磁盘空间）
.mo-gallery 总占用 = 资源库数据 + 网格缩略图 + 屏幕预览
```

## 命令

| 命令 | 目标 | 确认 | 结果 |
|---|---|---|---|
| 清理概览页缓存 | 概览、相机、镜头缓存 | 否 | 下次进入重新请求 |
| 清理云端照片列表缓存 | 分页数据与滚动位置 | 否 | 下次进入重新请求 |
| 清理 CacheStorage | 可枚举响应缓存 | 否 | 后续请求重新获取 |
| 清理并重建 | 全部应用数据缓存 | 是 | 页面数据在后续访问时重建 |
| 清理本地大图预览 | 2048px 屏幕预览 | 是 | 后续查看照片时按需重建 |
