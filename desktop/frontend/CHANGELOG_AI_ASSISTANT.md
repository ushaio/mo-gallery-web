# AI Assistant 输入框优化

## 变更内容

### 布局优化
- **水平布局重构**：聊天模型选择器（左）→ 生图模式切换（中）→ 生图参数（右，条件显示）
- **视觉层次**：生图按钮增加边框和背景色，激活状态更突出（琥珀色主题）
- **平滑过渡**：生图参数区域淡入 + 右滑动画（200ms ease-out）

### 控件统一
- **模型选择器**：添加边框，下拉菜单改为向上弹出（避免遮挡输入框）
- **尺寸选择器**：从原生 `<select>` 改为自定义下拉菜单，风格与模型选择器一致
  - 选项带图标：□ 1:1 正方形、▯ 9:16 竖版、▬ 16:9 横版
  - 支持键盘和鼠标操作

### 交互改进
- 聊天模式下不显示生图模型选择器，避免控件堆叠
- 生图参数仅在生图模式下显示，减少视觉噪音
- 所有下拉菜单点击外部自动关闭

## 技术细节

### 新增组件
- `DesktopImageSizeSelector`：图片尺寸选择下拉菜单（desktop\frontend\src\pages\AiAssistantPage.tsx:2456）

### 样式更新
- 添加 `@keyframes slideInFromRight` 动画（desktop\frontend\src\index.css:235）

### 修改文件
- `desktop/frontend/src/pages/AiAssistantPage.tsx`：输入框控件区域布局 + 尺寸选择器组件
- `desktop/frontend/src/index.css`：新增右滑入场动画
